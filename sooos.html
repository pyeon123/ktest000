Frequently Asked Questions

Q1. How do Koreans say "Fire extinguisher"?

소화기([so-hwa-gi/fire extinguisher]) is tool for putting out fire like red can to stop fire.

Q2. What is fire extinguisher location?

소화기 위치([so-hwa-gi wi-chi/fire extinguisher location]) is place where fire-stopping tool is like where is extinguisher.

Q3. What is using fire extinguisher?

소화기 사용([so-hwa-gi sa-yong/using fire extinguisher]) is action of using fire-stopping tool like pulling pin, spraying.
