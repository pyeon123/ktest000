Frequently Asked Questions

Q1. How do Koreans say "Standard / Specification"?

규격([gyu-gyeok/standard / specification]) is required size, thickness, weight for product from drawing or customer like 10mm, 5kg must match.

Q2. What is below specification?

규격 미달([gyu-gyeok mi-dal/below specification]) is when product size is smaller or worse than required rule like need 10mm but 9mm only.

Q3. What is specification sheet?

규격서([gyu-gyeok-seo/specification sheet]) is paper showing required size, thickness, weight, tolerance for product from customer.

EPS TOPIK Learn More: How to Say "Standard / Specification" in Korean - 규격([gyu-gyeok/standard / specification])

What does "규격([gyu-gyeok/standard / specification])" mean?

규격([gyu-gyeok/standard / specification]) means "standard / specification". It is required size, thickness, weight for product from drawing or customer like 10mm, 5kg must match.

Casual: 규격이야 (gyu-gyeok-i-ya)
Polite: 규격이에요 (gyu-gyeok-i-e-yo)
Formal: 규격입니다 (gyu-gyeok-im-ni-da)

Grammar Breakdown

규격([gyu-gyeok/standard / specification]) = 규 + 격 (rule + format)
규격 확인([gyu-gyeok hwa-gin/specification check]) = 규격 + 확인 (spec + check)
규격 미달([gyu-gyeok mi-dal/below specification]) = 규격 + 미달 (spec + below)
규격 외([gyu-gyeok oe/out of specification]) = 규격 + 외 (spec + outside)
규격서([gyu-gyeok-seo/specification sheet]) = 규격 + 서 (spec + document)

When to Use It (EPS-TOPIK Style)

1. Standard: “규격 어떻게 돼요? (gyu-gyeok eo-ttae-ke dwae-yo?)”
2. Check: 규격 확인([gyu-gyeok hwa-gin/specification check]) measure if matches drawing.
3. Sheet: 규격서([gyu-gyeok-seo/specification sheet]) document with required size, tolerance.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)
