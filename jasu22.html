Frequently Asked Questions

Q1. How do Koreans say "Embroidery"?

자수([ja-su/embroidery]) means decorating fabric by stitching patterns or logos with thread using a machine or by hand.

Q2. What is "Embroidery work" and "Embroidery machine"?

자수작업([ja-su-jak-eop/embroidery work]) is the actual embroidery job, and 자수기([ja-su-gi/embroidery machine]) is the automatic machine with many needles used for embroidery.

Q3. Why is "Embroidery completion" important in EPS-TOPIK?

자수완성([ja-su-wan-seong/embroidery completion]) means the embroidery is finished, and it is an important step before inspection and packaging.

EPS TOPIK Learn More: How to Say "Embroidery" in Korean - 자수([ja-su/embroidery])

What does "자수([ja-su/embroidery])" mean?

자수([ja-su/embroidery]) means "embroidery". It is decorating fabric by stitching patterns or logos with thread using a machine or by hand.

Casual: 자수야 (ja-su-ya)
Polite: 자수예요 (ja-su-ye-yo)
Formal: 자수입니다 (ja-su-im-ni-da)

Grammar Breakdown

자수([ja-su/embroidery]) = the core word for embroidery.
자수작업([ja-su-jak-eop/embroidery work]) = 자수 + 작업 (work)
자수기([ja-su-gi/embroidery machine]) = 자수 + 기 (machine)
자수문양([ja-su-mun-yang/embroidery pattern]) = 자수 + 문양 (pattern)
자수완성([ja-su-wan-seong/embroidery completion]) = 자수 + 완성 (completion)

When to Use It (EPS-TOPIK Style)

1. Daily work: “자수 했어요? (ja-su hae-sseo-yo?)”
2. Machine: Check the 자수기([ja-su-gi/embroidery machine]) before starting.
3. Completion: Report 자수완성([ja-su-wan-seong/embroidery completion]) after finishing.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 자수 했어요? A: ja-su hae-sseo-yo?

A: Did you do the embroidery?

B: 네, 했어요. B: ne, hae-sseo-yo.

B: Yes, I did.

A: 자수 잘 됐어요? A: ja-su jal dwae-sseo-yo?

A: Did the embroidery go well?

B: 네, 잘 됐어요. B: ne, jal dwae-sseo-yo.

B: Yes, it went well. - 자수([ja-su/embroidery])

A: 자수기 작동해요? A: ja-su-gi jak-dong-hae-yo?

A: Is the embroidery machine working?

B: 네, 작동해요. B: ne, jak-dong-hae-yo.

B: Yes, it is working.

A: 자수기 이상 있어요? A: ja-su-gi i-sang i-sseo-yo?

A: Is there a problem with the embroidery machine?

B: 아니요, 정상이에요. B: a-ni-yo, jeong-sang-i-e-yo.

B: No, it is normal. - 자수기([ja-su-gi/embroidery machine])

A: 자수문양 확인했어요? A: ja-su-mun-yang hwa-gin-hae-sseo-yo?

A: Did you check the embroidery pattern?

B: 네, 확인했어요. B: ne, hwa-gin-hae-sseo-yo.

B: Yes, I checked.

A: 자수문양 예쁘네요. A: ja-su-mun-yang ye-ppeu-ne-yo.

A: The embroidery pattern is pretty.

B: 네, 예뻐요. B: ne, ye-ppeo-yo.

B: Yes, it is pretty. - 자수문양([ja-su-mun-yang/embroidery pattern])

A: 자수완성 됐어요? A: ja-su-wan-seong dwae-sseo-yo?

A: Is the embroidery completed?

B: 네, 됐어요. B: ne, dwae-sseo-yo.

B: Yes, it is completed.

A: 자수완성 보고하세요. A: ja-su-wan-seong bo-go-ha-se-yo.

A: Please report the embroidery completion.

B: 네, 보고할게요. B: ne, bo-go-hal-ge-yo.

B: Yes, I will report it. - 자수완성([ja-su-wan-seong/embroidery completion])
