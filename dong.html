Frequently Asked Questions

Q1. How do Koreans say "Operation"?

작동([jak-dong/operation]) is when equipment, conveyor, robot moves and works like running state.

Q2. What is malfunction?

작동 불량([jak-dong bul-ryang/malfunction]) is when machine does not move or works wrongly like not starting.

Q3. What is automatic operation?

자동 작동([ja-dong jak-dong/automatic operation]) is when machine moves and works by itself without person like auto mode.

EPS TOPIK Learn More: How to Say "Operation" in Korean - 작동([jak-dong/operation])

What does "작동([jak-dong/operation])" mean?

작동([jak-dong/operation]) means "operation". It is when equipment, conveyor, robot moves and works like running state.

Casual: 작동이야 (jak-dong-i-ya)
Polite: 작동해요 (jak-dong-hae-yo)
Formal: 작동입니다 (jak-dong-im-ni-da)

Grammar Breakdown

작동([jak-dong/operation]) = 작 + 동 (make + move)
작동 확인([jak-dong hwa-gin/operation check]) = 작동 + 확인 (operation + check)
작동 불량([jak-dong bul-ryang/malfunction]) = 작동 + 불량 (operation + defect)
자동 작동([ja-dong jak-dong/automatic operation]) = 자동 + 작동 (auto + operation)
작동 중지([jak-dong jung-ji/operation stop]) = 작동 + 중지 (operation + stop)

When to Use It (EPS-TOPIK Style)

1. Operation: “작동 돼요? (jak-dong dwae-yo?)”
2. Check: 작동 확인([jak-dong hwa-gin/operation check]) checking if machine moves correctly.
3. Stop: 작동 중지([jak-dong jung-ji/operation stop]) stopping machine moving and working.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 작동 돼요? A: jak-dong dwae-yo?

A: Does operation work?

B: 네, 작동돼요. B: ne, jak-dong-dwae-yo.

B: Yes, operates.

A: 작동 안 돼요? A: jak-dong an dwae-yo?

A: Does operation not work?

B: 네, 안 돼요. B: ne, an dwae-yo.

B: Yes, not operating. - 작동([jak-dong/operation])

A: 작동 불량 있어요? A: jak-dong bul-ryang i-sseo-yo?

A: Is there malfunction?

B: 네, 불량 있어요. B: ne, bul-ryang i-sseo-yo.

B: Yes, malfunction.

A: 작동 불량 왜 생겼어요? A: jak-dong bul-ryang wae saeng-gyeo-sseo-yo?

A: Why malfunction?

B: 모터 고장 나서요. B: mo-teo go-jang na-seo-yo.

B: Motor broke. - 작동 불량([jak-dong bul-ryang/malfunction])

A: 자동 작동 돼요? A: ja-dong jak-dong dwae-yo?

A: Does automatic operation work?

B: 네, 돼요. B: ne, dwae-yo.

B: Yes, auto operates.

A: 자동 작동 중이에요? A: ja-dong jak-dong jung-i-e-yo?

A: Is it in automatic operation?

B: 네, 작동 중이에요. B: ne, jak-dong jung-i-e-yo.

B: Yes, in auto operation. - 자동 작동([ja-dong jak-dong/automatic operation])
