EPS TOPIK Learn More: How to Say "Insulation" in Korean - 절연([jeol-yeon/insulation])

What does "절연([jeol-yeon/insulation])" mean?

절연([jeol-yeon/insulation]) means "insulation". It is block electricity like rubber blocks power.

Casual: 절연이야 (jeol-yeon-i-ya)
Polite: 절연이에요 (jeol-yeon-i-e-yo)
Formal: 절연입니다 (jeol-yeon-im-ni-da)

Grammar Breakdown

절연([jeol-yeon/insulation]) = 절 + 연 (cut + connection)
절연 테이프([jeol-yeon te-i-peu/insulation tape]) = 절연 + 테이프 (insulation + tape)
절연 장갑([jeol-yeon jang-gap/insulating gloves]) = 절연 + 장갑 (insulation + gloves)
절연 상태([jeol-yeon sang-tae/insulation state]) = 절연 + 상태 (insulation + state)
절연 불량([jeol-yeon bul-lyang/poor insulation]) = 절연 + 불량 (insulation + poor)

When to Use It (EPS-TOPIK Style)

1. Insulation: “절연 됐어요? (jeol-yeon dwae-sseo-yo?)”
2. Tape: 절연 테이프([jeol-yeon te-i-peu/insulation tape]) tape for insulation.
3. Gloves: 절연 장갑([jeol-yeon jang-gap/insulating gloves]) gloves for insulation.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 절연 됐어요? A: jeol-yeon dwae-sseo-yo?

A: Is insulation done?

B: 네, 됐어요. B: ne, dwae-sseo-yo.

B: Yes, done.

A: 절연 왜 해요? A: jeol-yeon wae hae-yo?

A: Why insulation?

B: 감전 예방하려고요. B: gam-jeon ye-bang-ha-ryeo-go-yo.

B: To prevent shock. - 절연([jeol-yeon/insulation])

A: 절연 테이프 어디에 써요? A: jeol-yeon te-i-peu eo-di-e sseo-yo?

A: Where use insulation tape?

B: 전선 연결할 때 써요. B: jeon-seon yeon-gyeol-hal ttae sseo-yo.

B: When connecting wire.

A: 절연 테이프 어떻게 감아요? A: jeol-yeon te-i-peu eo-ttae-ke ga-ma-yo?

A: How wrap tape?

B: 꼼꼼하게 감아요. B: kkom-kkom-ha-ge ga-ma-yo.

B: Wrap thoroughly. - 절연 테이프([jeol-yeon te-i-peu/insulation tape])

A: 절연 장갑 왜 껴요? A: jeol-yeon jang-gap wae kkyeo-yo?

A: Why wear insulating gloves?

B: 감전 예방하려고요. B: gam-jeon ye-bang-ha-ryeo-go-yo.

B: To prevent shock.

A: 절연 장갑 어디에 있어요? A: jeol-yeon jang-gap eo-di-e i-sseo-yo?

A: Where gloves?

B: 공구함에 있어요. B: gong-gu-ham-e i-sseo-yo.

B: In toolbox. - 절연 장갑([jeol-yeon jang-gap/insulating gloves])
