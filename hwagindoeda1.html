Frequently Asked Questions

Q1. How do Koreans say "Be confirmed"?

확인되다([hwag-in-doe-da/be confirmed]) means to be verified or checked. In polite speech, say 확인돼요([hwag-in-dwae-yo]).

Q2. How do I say "was confirmed"?

확인됐어요([hwag-in-dwae-sseo-yo/was confirmed]) is the polite past form. Example: 확인됐어요 (It was confirmed / verified).

Q3. How do I say "have to be confirmed"?

확인돼야 해요([hwag-in-dwae-ya hae-yo/have to be confirmed]) means it must be verified. Example: 확인돼야 해요 (It has to be confirmed).

EPS TOPIK Learn More: How to Say "Be confirmed" in Korean - 확인되다([hwag-in-doe-da/be confirmed])

What does "확인되다([hwag-in-doe-da/be confirmed])" mean?

확인되다([hwag-in-doe-da/be confirmed]) means "to be confirmed". To be verified, checked, validated.

Casual: 확인돼 (hwag-in-dwae)
Polite: 확인돼요 (hwag-in-dwae-yo)
Formal: 확인됩니다 (hwag-in-doem-ni-da)

Grammar Breakdown

확인되다([hwag-in-doe-da/be confirmed]) = 확인 (confirmation) + 되다 (become)
확인됐어요([hwag-in-dwae-sseo-yo/was confirmed]) = 확인됐 + 어요 (was confirmed + polite)
확인되고 싶어요([hwag-in-doe-go si-peo-yo/want to be confirmed]) = 확인되 + 고 싶어요 (be confirmed + want to)
확인돼야 해요([hwag-in-dwae-ya hae-yo/have to be confirmed]) = 확인돼 + 야 해요 (be confirmed + have to)
확인되지 마세요([hwag-in-doe-ji ma-se-yo/don't be confirmed]) = 확인되 + 지 마세요 (be confirmed + please don't)

When to Use It (EPS-TOPIK Style)

1. Daily: “확인돼요? (hwag-in-dwae-yo)” Is it confirmed?
2. Past: 확인됐어요([hwag-in-dwae-sseo-yo/was confirmed]) was confirmed.
3. Duty: 확인돼야 해요([hwag-in-dwae-ya hae-yo/have to be confirmed]) have to be confirmed.
4. Warning: 확인되지 마세요([hwag-in-doe-ji ma-se-yo/don't be confirmed]) don't be confirmed.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 확인돼요? A: hwag-in-dwae-yo?

A: Is it confirmed?

B: 네, 확인돼요. B: ne, hwag-in-dwae-yo.

B: Yes, it is confirmed.

A: 언제 확인돼요? A: eon-je hwag-in-dwae-yo?

A: When is it confirmed?

B: 지금 확인돼요. B: ji-geum hwag-in-dwae-yo.

B: It is confirmed now. - 확인되다([hwag-in-doe-da/be confirmed])

A: 확인됐어요? A: hwag-in-dwae-sseo-yo?

A: Was it confirmed?

B: 네, 확인됐어요. B: ne, hwag-in-dwae-sseo-yo.

B: Yes, it was confirmed.

A: 언제 확인됐어요? A: eon-je hwag-in-dwae-sseo-yo?

A: When was it confirmed?

B: 어제 확인됐어요. B: eo-je hwag-in-dwae-sseo-yo.

B: It was confirmed yesterday. - 확인됐어요([hwag-in-dwae-sseo-yo/was confirmed])

A: 언제 확인돼야 해요? A: eon-je hwag-in-dwae-ya hae-yo?

A: When does it have to be confirmed?

B: 오늘 확인돼야 해요. B: o-neul hwag-in-dwae-ya hae-yo.

B: It has to be confirmed today.
