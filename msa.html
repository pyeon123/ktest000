Frequently Asked Questions

Q1. How do Koreans say "Inspection"?

검사([geom-sa/inspection]) is checking products for defects like visual, size, function to find bad items.

Q2. What is inspection criteria?

검사기준([geom-sa-gi-jun/inspection criteria]) is rules for inspection like size must be 10mm, no scratch, function must work.

Q3. What is quality inspection?

품질검사([pum-jil-geom-sa/quality inspection]) is checking final product quality like appearance, function, safety before shipping.

EPS TOPIK Learn More: How to Say "Inspection" in Korean - 검사([geom-sa/inspection])

What does "검사([geom-sa/inspection])" mean?

검사([geom-sa/inspection]) means "inspection". It is checking products for defects like visual, size, function to find bad items.

Casual: 검사야 (geom-sa-ya)
Polite: 검사예요 (geom-sa-ye-yo)
Formal: 검사입니다 (geom-sa-im-ni-da)

Grammar Breakdown

검사([geom-sa/inspection]) = 검 + 사 (examine + check)
검사작업([geom-sa-ja-geop/inspection work]) = 검사 + 작업 (inspection + work)
검사기준([geom-sa-gi-jun/inspection criteria]) = 검사 + 기준 (inspection + criteria)
검사결과([geom-sa-gyeol-gwa/inspection result]) = 검사 + 결과 (inspection + result)
품질검사([pum-jil-geom-sa/quality inspection]) = 품질 + 검사 (quality + inspection)

When to Use It (EPS-TOPIK Style)

1. Inspection: “검사 했어요? (geom-sa hae-sseo-yo?)”
2. Criteria: 검사기준([geom-sa-gi-jun/inspection criteria]) must follow manual.
3. Result: 검사결과([geom-sa-gyeol-gwa/inspection result]) pass or fail.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 검사 했어요? A: geom-sa hae-sseo-yo?

A: Did you do inspection?

B: 네, 했어요. B: ne, hae-sseo-yo.

B: Yes, inspected.

A: 검사 어떻게 해요? A: geom-sa eo-ttae-ke hae-yo?

A: How to inspect?

B: 눈으로 해요. B: nun-eu-ro hae-yo.

B: By eyes. - 검사([geom-sa/inspection])

A: 검사기준 뭐예요? A: geom-sa-gi-jun mwo-ye-yo?

A: What is inspection criteria?

B: 10mm예요. B: 10mm-ye-yo.

B: 10mm.

A: 검사기준 어디 있어요? A: geom-sa-gi-jun eo-di i-sseo-yo?

A: Where is inspection criteria?

B: 매뉴얼에 있어요. B: mae-nyu-eol-e i-sseo-yo.

B: In manual. - 검사기준([geom-sa-gi-jun/inspection criteria])

A: 검사결과 어때요? A: geom-sa-gyeol-gwa eo-ttae-yo?

A: How is inspection result?

B: 합격이에요. B: hap-gyeok-i-e-yo.

B: Pass.

A: 검사결과 보고했어요? A: geom-sa-gyeol-gwa bo-go-hae-sseo-yo?

A: Did you report inspection result?

B: 네, 보고했어요. B: ne, bo-go-hae-sseo-yo.

B: Yes, reported. - 검사결과([geom-sa-gyeol-gwa/inspection result])
