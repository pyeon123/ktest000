Frequently Asked Questions

Q1. How do Koreans say "Saw"?

톱([top/saw]) is cutting wood tool like cut wood with toothed tool.

Q2. What is hand saw?

손톱([son-top/hand saw]) is hand saw like saw using hand.

Q3. What is cut with saw?

톱으로 자르다([top-eu-ro ja-reu-da/cut with saw]) is cut using saw like cut wood using saw.

EPS TOPIK Learn More: How to Say "Saw" in Korean - 톱([top/saw])

What does "톱([top/saw])" mean?

톱([top/saw]) means "saw". It is cutting wood tool like cut wood with toothed tool.

Casual: 톱이야 (to-bya)
Polite: 톱이에요 (to-bie-yo)
Formal: 톱입니다 (to-bim-ni-da)

Grammar Breakdown

톱([top/saw]) = 톱 (saw)
손톱([son-top/hand saw]) = 손 + 톱 (hand + saw)
톱으로 자르다([top-eu-ro ja-reu-da/cut with saw]) = 톱으로 + 자르다 (with saw + cut)
톱날([top-nal/saw blade]) = 톱 + 날 (saw + blade)
쇠톱([soe-top/hacksaw]) = 쇠 + 톱 (iron + saw)

When to Use It (EPS-TOPIK Style)

1. Saw: “톱 어디 있어요? (top eo-di i-sseo-yo?)”
2. Hand: 손톱([son-top/hand saw]) hand saw.
3. Cut: 톱으로 자르다([top-eu-ro ja-reu-da/cut with saw]) cut using saw.

Real-Life Examples - A-B-A-B Dialogue (EPS-TOPIK)

A: 톱 어디 있어요? A: top eo-di i-sseo-yo?

A: Where saw?

B: 공구함에 있어요. B: gong-gu-ham-e i-sseo-yo.

B: In toolbox.

A: 톱 좀 빌려줘요. A: top jom bil-lyeo-jwo-yo.

A: Lend saw please.

B: 네, 여기 있어요. B: ne, yeo-gi i-sseo-yo.

B: Yes, here. - 톱([top/saw])

A: 손톱 어디에 써요? A: son-top eo-di-e sseo-yo?

A: Where use hand saw?

B: 나무 자를 때 써요. B: na-mu ja-reul ttae sseo-yo.

B: When cutting wood.

A: 손톱으로 자르기 쉬워요? A: son-top-eu-ro ja-reu-gi swi-wo-yo?

A: Easy to cut with hand saw?

B: 네, 쉬워요. B: ne, swi-wo-yo.

B: Yes, easy. - 손톱([son-top/hand saw])

A: 톱으로 뭘 잘라요? A: to-beu-ro mwol jal-la-yo?

A: What cut with saw?

B: 나무를 잘라요. B: na-mu-reul jal-la-yo.

B: Cut wood.

A: 톱으로 자르기 힘들어요? A: to-beu-ro ja-reu-gi him-deul-eo-yo?

A: Hard to cut with saw?

B: 조금 힘들어요. B: jo-geum him-deul-eo-yo.

B: A little hard. - 톱으로 자르다([top-eu-ro ja-reu-da/cut with saw])
